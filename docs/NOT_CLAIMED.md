# What this repo is not

- Not automatic target recognition, ISR, or a targeting product.
- Not loitering munitions, anti-drone, or combat-vehicle vision.
- Not a continent-scale foundation-model fine-tune.
- Not a campus NeRF / digital twin.
- Not a Kaggle wildfire globe.
- Class lists stay civilian: water, pond, vegetation, building, vehicle, person, boat, other.
- README metrics come from `experiments/` after a real tile run.
