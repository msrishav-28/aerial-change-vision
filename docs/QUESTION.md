# Question

On a *civilian* area of interest, using public EO and optional SAR,
what changed between date A and date B — or what is present in a
drone sequence — when the model is tested on a scene it was not
trained on?

**Unit of analysis:** a scene / flight / date-pair / AOI tile group.
Never a random pixel or a random chip from the same scene.

**Not the question:** "Detect military assets from orbit."
